## ✨ Conoce Expensal

**Expensal** es una aplicación web de organización financiera personal, diseñada para hacer más sencillo el seguimiento de ingresos, gastos, presupuestos y objetivos de ahorro.

Con una interfaz clara, modo oscuro y un enfoque especial en las necesidades de Costa Rica, busca transformar los registros diarios en información útil para tomar decisiones mejor fundamentadas.

## 🧩 Funcionalidades

|:--|:--|
| **📊 Panel y resumen** | Consultar ingresos, gastos, balance y distribución por categorías. |

## 💚 Metas de ahorro que se adaptan a ti

Expensal permite crear objetivos de ahorro personales, registrar dinero que ya se tiene ahorrado, **reservar virtualmente** parte del dinero disponible y consultar posibles estrategias de aportación.

El sistema puede identificar desviaciones con respecto a una meta y presentar opciones para ajustar el importe o el plazo. **No mueve dinero de cuentas bancarias ni modifica automáticamente las decisiones del usuario.**

## 🌎 Idiomas y monedas

- **Idiomas:** español e inglés.
- **Moneda inicial para nuevas visitas:** colón costarricense (CRC).
- **Otras monedas compatibles:** USD, BTC, ETH y USDT.
- **Cotizaciones:** referencias semanales utilizadas por la aplicación para mantener consistencia entre conversiones durante el período correspondiente.
- **Personalización:** modo claro/oscuro y preferencias de idioma y moneda.

## 🔐 Privacidad y respaldos

La información financiera personal se gestiona principalmente en el **almacenamiento local del navegador**. La aplicación permite generar respaldos e importarlos para recuperar la información en otro dispositivo.

- No se requiere crear una cuenta para llevar el control financiero.
- El usuario es responsable de conservar sus archivos de respaldo: limpiar los datos del navegador podría eliminar la información local.
- Los respaldos exportados **no sustituyen un almacenamiento cifrado de alta seguridad**. Protégelos como cualquier archivo que contenga información financiera.
- El formulario de soporte y las consultas de cotizaciones pueden comunicarse con servicios externos.
